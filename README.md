# HPC Resources

Beginner-friendly tutorials for using high-performance computing (HPC) systems, made for students who are new to clusters and the command line.

## 📖 Start here

**All tutorials live in the [Wiki](https://github.com/hensonjc/hpc/wiki).** Click the link here, or the **Wiki** tab at the top of this page, to get started.

## What's covered

- Logging in and connecting to a cluster
- Basic Linux commands
- Running your first job with UOG EPSCoR HTCondor Cluster
- Common errors and how to fix them

## Who this is for

No prior experience with clusters, Linux, or command-line tools is needed. Each tutorial explains things step by step, including exact commands to copy and paste.
